He analizado tu código y encontré el problema principal: el mapa no se está renderizando porque el contenedor #map no tiene altura definida correctamente en el CSS de escritorio.

🔍 Problema detectado
En tu dashboard.css, en la sección de escritorio (@media (min-width: 769px)), el contenedor #map está dentro de .map-wrapper, pero no tiene una altura explícita.

Actualmente tienes:

css
.map-wrapper {
    flex: 0 0 70%;
    max-width: 70%;
    position: relative;
    height: 100%;  /* ✅ Esto está bien */
    transition: all 0.3s ease;
}

#map {
    width: 100%;
    height: 100%; /* ✅ Esto también está bien */
}
Pero el problema real es que algunas reglas de CSS están sobrescribiendo el display y el layout en la sección "NUEVAS REGLAS" al final del archivo.

🛠️ Solución
Agrega este CSS al final de tu dashboard.css (o modifica las reglas existentes):

css
/* =======================================
   FIX: Asegurar que el mapa se vea en Desktop
======================================= */

/* Asegurar que el contenedor principal ocupe toda la altura */
.layout-wrapper {
    height: 100vh;
    overflow: hidden;
}

.content-wrapper {
    height: 100vh;
    overflow: hidden;
    flex: 1;
    display: flex;
    flex-direction: column;
}

/* Vista Mapa: asegurar altura completa */
#vistaMapa {
    flex: 1;
    display: flex !important;
    flex-direction: column;
    height: 100%;
    min-height: 0; /* Importante para flex */
}

/* Map wrapper: ocupa todo el espacio disponible */
.map-wrapper {
    flex: 1 !important;
    min-height: 0 !important;
    height: 100% !important;
    max-width: 100% !important;
    display: flex !important;
    flex-direction: column !important;
    position: relative !important;
}

/* El mapa debe ocupar todo el wrapper */
#map {
    flex: 1 !important;
    width: 100% !important;
    height: 100% !important;
    min-height: 400px !important; /* Altura mínima para que se vea */
}

/* En desktop, el panel de filtros no debe bloquear el mapa */
@media (min-width: 769px) {
    #panelFiltros {
        position: fixed !important;
        top: 50% !important;
        left: 50% !important;
        transform: translate(-50%, -50%) scale(0.95) !important;
        width: min(380px, 92vw) !important;
        max-height: 90vh !important;
        z-index: 9999 !important;
        display: flex !important;
        flex-direction: column !important;
        opacity: 0 !important;
        visibility: hidden !important;
        transition: all 0.25s ease !important;
        border-radius: 14px !important;
        background: var(--bg-card) !important;
        border: 1px solid var(--borde) !important;
        box-shadow: var(--sombra) !important;
    }

    #panelFiltros.abierto {
        opacity: 1 !important;
        visibility: visible !important;
        transform: translate(-50%, -50%) scale(1) !important;
    }

    /* Asegurar que el overlay funcione correctamente */
    .filtros-overlay {
        display: block !important;
        position: fixed !important;
        inset: 0 !important;
        z-index: 9998 !important;
        background: rgba(0, 0, 0, 0.6) !important;
        opacity: 0 !important;
        visibility: hidden !important;
        transition: all 0.25s ease !important;
    }

    .filtros-overlay.visible {
        opacity: 1 !important;
        visibility: visible !important;
    }

    /* Quitar cualquier overflow que pueda ocultar el mapa */
    body {
        overflow: hidden !important;
    }

    .content-wrapper {
        overflow: hidden !important;
    }

    /* Asegurar que el footer no tape el mapa */
    .sigi-footer {
        position: relative !important;
        flex-shrink: 0 !important;
        padding: 10px 20px !important;
        background: var(--bg-card) !important;
        border-top: 1px solid var(--borde) !important;
    }
}
📝 Explicación del Fix
min-height: 0 en contenedores flex: evita que los elementos flex se desborden

flex: 1 en .map-wrapper y #map: asegura que ocupen todo el espacio disponible

!important en reglas críticas: sobrescribe cualquier conflicto de especificidad

min-height: 400px en #map: garantiza que el mapa tenga al menos esa altura aunque el contenedor no esté dimensionado

Panel de filtros como modal en desktop: evita que interfiera con el layout del mapa

🚀 Si después de esto aún no funciona
Puede ser que el mapa no se esté inicializando porque dashboard.js se carga después de que Leaflet intenta renderizar. Prueba esto:

En dashboard.js, justo después de donde se crea el mapa, agrega:

javascript
// Forzar actualización del tamaño del mapa después de que la página cargue
document.addEventListener('DOMContentLoaded', function() {
    setTimeout(() => {
        if (typeof map !== 'undefined') {
            map.invalidateSize();
            console.log('✅ Mapa refrescado');
        }
    }, 300);
});

// También al cambiar de vista
window.addEventListener('resize', function() {
    if (typeof map !== 'undefined') {
        map.invalidateSize();
    }
});
🔍 Verificación rápida
Abre la consola del navegador (F12) y escribe:

javascript
document.getElementById('map').offsetHeight
Si devuelve 0 o un número muy pequeño, el mapa no tiene altura. Si devuelve un número positivo (ej: 600), el mapa tiene altura y el problema es otro (probablemente que Leaflet no se inicializó correctamente).
